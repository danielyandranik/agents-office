We paraphrase its three non-negotiables (reproduce before fixing, fix root causes rather than sleeps/timeouts/retries/weakened assertions, validate with an N-run loop), its N = max(3k, 20) loop sizing with a 50-run default when the rate is unknown, and its list of masking fixes. The workflow is rewritten for Agent Office: no PostHog `hogli` tooling and no GitHub Actions API; cause classes regrouped into timing, order dependence, shared state, environment, nondeterministic data and external services.
